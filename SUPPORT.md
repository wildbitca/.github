# Support

## Where to ask

Open an issue on the specific repository your question is about. Issues are enabled on:

- [ai-resources](https://github.com/wildbitca/ai-resources/issues)
- [org-gitops](https://github.com/wildbitca/org-gitops/issues)
- [avasambench](https://github.com/wildbitca/avasambench/issues)
- [cloudflare-prometheus-exporter](https://github.com/wildbitca/cloudflare-prometheus-exporter/issues)

Issues are disabled on the other repositories in the organization (including the
Crossplane providers). If the repository you have a question about does not have
issues enabled, please use one that does — there is no other queue to route it to.

None of our repositories have GitHub Discussions enabled.

## No SLA

This is not a paid support channel. There is no guaranteed response time.

## Support the work

If you'd like to support this work, you can do so through
[GitHub Sponsors](https://github.com/sponsors/wildbitca). No specific benefits are
promised in exchange for sponsorship.
